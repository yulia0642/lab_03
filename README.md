# Каталог библиотечных книг

Проект реализует предметную модель `Book`, каталог книг и сохранение каталога в JSON.

## Структура

```text
src/catalog/
    __init__.py
    models.py       # модель Book и проверка полей
    exceptions.py   # исключения предметной области
    catalog.py      # операции каталога и индексы
    storage.py      # сохранение и загрузка JSON

tests/
    test_catalog.py
```

## Установка

Из корневой папки проекта в PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -e ".[dev]"
```

## Пример использования

```python
from catalog import Book, Catalog

catalog = Catalog()
book = Book(
    book_id="B001",
    title="Преступление и наказание",
    category="Роман",
    year=1866,
    author="Фёдор Достоевский",
    isbn="ISBN-13: 978-5-17-090738-2",
)
catalog.add(book)
print(catalog.get("B001"))
catalog.save("books.json")

another_catalog = Catalog()
another_catalog.load("books.json")
```

## Возможности

- Проверка полей книги при создании объекта `Book`.
- Уникальность `book_id` внутри каталога.
- Поиск по ID через словарь: в среднем O(1).
- Поиск по категории через дополнительный индекс.
- Поиск по названию без учёта регистра.
- `len(catalog)`, перебор `for book in catalog` и проверка `book_id in catalog`.
- Порядок перебора — порядок добавления книг.
- Поиск возвращает новый список, а не внутреннюю коллекцию каталога.
- JSON содержит номер версии формата.
- При ошибке загрузки текущий каталог не меняется: данные сначала полностью читаются и проверяются во временных структурах.

## Принятые решения

- Уникальность ID проверяет `Catalog`, потому что она зависит от других книг каталога.
- `Book` проверяет собственные поля. Для ISBN проверяется длина и допустимые символы ISBN-10/ISBN-13; контрольная цифра не проверяется.
- Категории сравниваются без учёта регистра.
- Поиск по названию выполняется по вхождению подстроки без учёта регистра.
- JSON-формат текущей версии — `1`.
