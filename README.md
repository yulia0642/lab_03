# Library Catalog

Каталог библиотечных книг с проверкой данных,
поиском, удалением, а также сохранением и загрузкой каталога в формате JSON.

## Возможности

Программа позволяет:

-   создавать книги с полями `book_id`, `title`, `category`, `year`,
    `author` и `isbn`;
-   проверять корректность данных книги при создании;
-   добавлять книги в каталог и запрещать повторяющиеся ID;
-   получать книгу по ID и удалять её;
-   искать книги по категории и по части названия без учёта регистра;
-   перебирать книги в порядке их добавления и получать количество книг
    в каталоге;
-   сохранять каталог в JSON-файл и загружать его обратно;
-   обрабатывать ошибки: некорректные данные, повторяющийся или
    отсутствующий ID, повреждённый файл и неподдерживаемую версию
    формата.

## Требования

-   Python 3.12 или новее
-   `pip`

## Установка и запуск на macOS

Откройте Terminal и перейдите в папку проекта. 
Создайте виртуальное окружение:

``` bash
python3 -m venv .venv
```

Активируйте его:

``` bash
source .venv/bin/activate
```

Установите проект и инструменты для разработки и тестирования:

``` bash
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

После установки запустите демонстрацию работы программы:

Если виртуальное окружение больше не нужно, его можно деактивировать:

``` bash
deactivate
```

## Установка и запуск на Windows

Создайте и активируйте виртуальное окружение:

``` powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите проект и инструменты разработки:

``` powershell
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```


## Проверка работы программы

Для проверки основного сценария выполните из корневой папки проекта:

``` bash
python main.py
```

В ходе демонстрации программа создаёт и использует объекты книг и
каталог, показывает работу его операций и сохранение/загрузку данных.
Результат выполнения выводится в терминал.

Файл `books.json` содержит данные каталога в JSON-формате. Его можно
открыть любым текстовым редактором, чтобы посмотреть сохранённую
структуру. Если программа перезаписывает этот файл при очередном
запуске, перед запуском сохраните копию нужных данных.

## Запуск тестов

Тесты проверяют валидацию книг, операции каталога, поиск, специальные
методы, сохранение и загрузку JSON, а также обработку некорректных
файлов.

Запустить все тесты:

``` bash
python -m pytest
```

Запустить тесты с подробным выводом:

``` bash
python -m pytest -v
```

При успешном прохождении pytest покажет итоговую сводку, например:

``` text
6 passed
```

Тесты используют временные файлы и временную папку `tmp_path`; для их
выполнения не требуется вручную создавать тестовые JSON-файлы.

## Использование каталога в собственном Python-коде

Основные классы и исключения доступны из пакета `catalog`.

``` python
from catalog import Book, Catalog

catalog = Catalog()

book = Book(
    "B001",
    "Преступление и наказание",
    "Роман",
    1866,
    "Фёдор Достоевский",
    "978-5-17-090738-2",
)

catalog.add(book)

# Получить книгу по ID
found_book = catalog.get("B001")
print(found_book)

# Найти книги по категории
books_by_category = catalog.find_by_category("Роман")

# Найти книги по части названия
books_by_name = catalog.find_by_name("преступление")

# Проверить количество книг
print(len(catalog))

# Проверить наличие ID
print("B001" in catalog)

# Перебрать книги
for item in catalog:
    print(item)

# Удалить книгу
catalog.remove("B001")
```

Сохранение и загрузка каталога:

``` python
from catalog.storage import load_catalog, save_catalog

save_catalog(catalog, "books.json")

another_catalog = Catalog()
load_catalog(another_catalog, "books.json")
```

Также сохранение и загрузка доступны через методы самого каталога:

``` python
catalog.save("books.json")
catalog.load("books.json")
```

При ошибках операции выбрасывают предметные исключения из `catalog`,
например `InvalidBookError`, `DuplicateIDError`, `BookNotFoundError` и
`CorruptedFileError`.

## Структура проекта

``` text
lab_03/
├── src/
│   └── catalog/
│       ├── __init__.py
│       ├── catalog.py
│       ├── exceptions.py
```

-   `models.py` --- модель книги и проверка её полей.

-   `main.py` --- демонстрационный сценарий работы.
-   `tests/` --- автоматические тесты.
-   `pyproject.toml` --- настройки проекта и зависимости.
